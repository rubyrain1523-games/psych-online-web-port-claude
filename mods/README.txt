Put zipped mods here (one .zip per mod, e.g. my-mod.zip, max 100 MB each).
When the game loads on GitHub Pages it downloads any new or changed zips from this folder and installs them automatically.
Mods are stored in the browser, so each player/browser installs them once.
The zip should contain the mod folder (with pack.json / songs / data / images etc.).
After uploading a zip, wait for GitHub Pages to update (1-3 minutes) and reload the game.
