# Play offline (everything included)

1. Download the whole repo as one zip: **https://github.com/rubyrain1523-games/psych-online-web-port-claude/archive/refs/heads/main.zip**
   (or the green **Code** button -> **Download ZIP**). It contains every game asset, about 550 MB.
2. Extract it, open the `PsychOnline-Web` folder.
3. Easiest: run `start-server.bat` (Windows, needs Python) or `python3 serve.py`, then open http://localhost:8123 in Chrome.
4. No Python: double-click `index.html`, pick a mode, and when asked choose that same `PsychOnline-Web` folder.

Online rooms and sign-in still need internet. Hidden (about:blank) mode only works from the hosted site.
